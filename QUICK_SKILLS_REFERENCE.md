## 💡 Pro Tips

1. **Combine Skills**: Use multiple skills for complex tasks
   - Example: Use `ux-designer` + `ui-styling` + `frontend-design` together

2. **Sequential Workflow**: Chain skills for end-to-end features
   - Example: `brainstorming` → `senior-pm` → `senior-fullstack` → `senior-qa`

3. **Iterative Improvement**: Use review skills after implementation
   - Example: Implement with `senior-frontend`, then review with `ui-design-review`

4. **Specialized Deep-Dives**: Use senior skills for complex problems
   - Example: For complex data issues, use `senior-data-engineer` or `senior-data-scientist`
